# 🧠 Memory Card Game

A fun and interactive browser-based **Memory Card Game** built with HTML, CSS, and JavaScript.

Flip two cards at a time, remember their positions, and match all the pairs using as few moves as possible.

> 🎯 **Practice Project by Md. Shafin Al Shadab**

---

## 🎮 About The Game

**Memory Card Game** is a simple browser game designed to test and improve your memory.

All cards start face-down. Click a card to reveal its symbol, then select another card and try to find its matching pair.

If the two cards match, they remain open.

If they don't match, they are flipped back so you can try again.

Your goal is to match every pair with the **fewest possible moves** and in the **shortest possible time**.

---

## ✨ Features

- 🃏 16 cards / 8 matching pairs
- 🔀 Random card shuffling
- 🖱️ Interactive card clicking
- 🔄 Card flip animation
- 🧠 Memory-based gameplay
- 🎯 Match detection
- ❌ Automatic wrong-pair reset
- 🔒 Prevents accidental clicks during card comparison
- 📊 Move counter
- ⏱️ Live game timer
- 🏆 Match progress tracker
- 🎉 Win detection
- 🔄 New Game button
- 📱 Responsive design
- ✨ Modern glassmorphism-inspired interface
- 🌈 Gradient-based visual design
- 🚫 No external libraries required
